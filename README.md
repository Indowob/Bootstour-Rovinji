# Bootstour Rovinj

Tourplan für einen Tagesausflug mit dem Boot ab Camping Veštar bei Rovinj, Istrien.

**Live:** https://indowob.github.io/Bootstour-Rovinji/

## Inhalt

- Route mit vier Stopps und Google-Maps-Links
- Kürzere Alternativroute
- Regeln für Limski kanal, Delfinbeobachtung und Ankern
- Spritkalkulation
- Checkliste für den Tag

## Dateien

| Datei | Zweck |
|---|---|
| `index.html` | Die komplette Seite. Eigenständig, kein externes CSS oder JS. |
| `README.md` | Diese Datei. |

## GitHub Pages einrichten

1. `index.html` liegt im Wurzelverzeichnis des Repositories (nicht in einem Unterordner).
2. Im Repository: **Settings → Pages**
3. Unter **Source**: `Deploy from a branch`
4. Branch: `main`, Ordner: `/ (root)` → **Save**
5. Nach ein bis zwei Minuten ist die Seite unter der oben genannten Adresse erreichbar.

## Technisches

Einzelne HTML-Datei ohne Abhängigkeiten. Responsive ab 320 px Breite, unterstützt hellen und dunklen Systemmodus.
